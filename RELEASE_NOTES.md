Simple native macOS timer with an editable title, keyboard time entry, a resizable window, and an Always on Top toggle.

Download **SimpleTimer-macOS-AppleSilicon.zip**, unzip it, then move **SimpleTimer.app** to Applications.

Requires **Apple Silicon and macOS 14 or later**.

This development build is ad-hoc signed and has not been notarized by Apple. macOS may prevent it from opening. Only if you trust the downloaded app, attempt to open it, then use **System Settings → Privacy & Security → Open Anyway** if available.
